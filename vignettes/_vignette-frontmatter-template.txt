3. SETUP CHUNK  (ready to copy-paste)
-----------------------------------------------------------------------

This is the FIRST chunk of every vignette. include = FALSE on this
chunk is correct (no output is interesting). On every subsequent
primary-call chunk, include = FALSE is forbidden.

```{r setup, include = FALSE}
knitr::opts_chunk$set(
  echo       = TRUE,
  results    = "markup",   # never "hide" for primary calls
  comment    = "#>",
  collapse   = TRUE,
  message    = FALSE,
  warning    = FALSE,
  fig.width  = 7,
  fig.height = 4.5,
  fig.retina = 2,
  dpi        = 144,
  fig.align  = "center",
  out.width  = "100%"
)
set.seed(1L)
library(multisiteDGP)
library(ggplot2)
```

NOTES ON OPTIONS
- echo = TRUE          ensures the reader sees the call.
- results = "markup"   ensures the reader sees the result. Suppressing
                       this is the single most-flagged failure mode in
                       the audit (rows M-5, M-7, M-8, M-9).
- comment = "#>"       prefixes printed output (DPprior convention).
- collapse = TRUE      collapses code+output into a single block.
- fig.retina = 2       crisp plots on hidpi displays.
- out.width = "100%"   plots fill the article column.
- set.seed(1L)         determinism. The hash for
                       sim_multisite(preset_jebs_paper(), seed = 1L)
                       is c52e75f276d82836 - use as a smoke check.
- library(multisiteDGP), library(ggplot2): load both up front. If a
  vignette needs a soft dep (metafor, baggr, multisitepower), load it
  inside a \dontrun-style guarded chunk - do NOT add it to the setup.

HELPER VS PRIMARY CHUNKS
- Helper-only chunks (e.g., constructing a fake calibration target,
  building an annotation tibble for ggplot) MAY use include = FALSE.
- Primary calls (any user-facing function from NAMESPACE: sim_multisite,
  sim_meta, presets, scenario_audit, compute_I, compute_kappa,
  compute_shrinkage, informativeness, mean_shrinkage,
  feasibility_index, heterogeneity_ratio, realized_rank_corr,
  realized_rank_corr_marginal, bhattacharyya_coef, ks_distance,
  default_thresholds, plot_effects, plot_funnel, plot_dependence,
  as_metafor, as_baggr, as_multisitepower, canonical_hash,
  provenance_string, design_grid, multisitedgp_design,
  validate_multisitedgp_design, gen_*) MUST show output.

5. FAILURE-MODE GUARD LIST
-----------------------------------------------------------------------

Eight failure modes documented in prior phases (handoff §8). For each:
description, then mitigation.

5.1  Citation hallucination
     Walters JEP fabrication (Round 1), 3-of-3 sim_meta JEBS
     hallucinations (Phase 5 Step 5.3), Weiss 2014 mis-attribution
     (Round 1).
     -> Only cite from references.bib. For anything else, mark
        [CITATION TBD - PI to confirm: ...] in the prose. Do not retype
        an entry from memory; copy it verbatim.

5.2  Function-name fabrication
     Real export is gen_effects_pmslab, not gen_effects_pointmassslab
     (Step 5.4). presets$balanced_small does not exist (Step 5.2).
     -> Every function call in a vignette must use a name listed in
        NAMESPACE. The 53 exports + 28 S3 methods are the source of
        truth. Run `grep '^export' multisiteDGP-R-package/NAMESPACE`
        to confirm any name before using it.

5.3  Vignette slug invention
     D1 in Step 6.4 wrote vignette("a3-diagnostic-grid") - real slug
     is a3-diagnostics-in-practice. Synthesis caught.
     -> Use the 16-slug map in §1 of this template verbatim. Do not
        compose plausible-sounding alternatives.

5.4  Prohibited-phrase drift
     "Paradigm A" bare, "Layer 1-4 pipeline", "dispatches to",
     "catalog Layer 1 routes", "v1", "Gate E", etc.
     -> Scan with the script in handoff §9.3. First use of "Paradigm A"
        must be glossed: "the *site-size-driven* path (Paradigm A in
        the blueprint)".

5.5  Assign-and-hide chunks
     Audit row M-9 (cookbook.Rmd) and rows M-5/M-7/M-8 (v2/v5/v6) all
     fail by suppressing output for primary calls. The reader cannot
     see what the function returns.
     -> include = FALSE only on helper chunks. Every primary call
        renders its tibble or scalar in the next visible block.

5.6  Decorative-only plots
     A plot whose caption explains what the plot IS (e.g., "Histogram
     of per-site sampling variances") rather than what to read off it.
     -> Caption template: "<observation> <axis or region of plot>,
        confirming/contradicting <design target or hypothesis>."
        Example: "Tail mass concentrates above se^2 = 0.5, confirming
        the R = 4 heterogeneity target."

5.7  Forgetting to set seed = 1L
     Determinism breaks; the published vignette and the reader's local
     re-run diverge.
     -> set.seed(1L) in setup chunk AND seed = 1L on every call that
        accepts a seed argument (sim_multisite, sim_meta, gen_effects,
        gen_observations, etc.). The hash
        sim_multisite(preset_jebs_paper(), seed = 1L) ->
        c52e75f276d82836 is a determinism smoke check.

5.8  Stale post-adapter column names
     F-3 in Phase 6 caught examples that, after as_metafor(dat),
     referenced dat$tau_j_hat instead of yi/vi/sei. The example would
     not run.
     -> After as_metafor() use yi / vi / sei. After as_baggr() and
        as_multisitepower() check the actual rename function in
        R/adapters.R lines 130-165 before referencing columns.

7. OPEN QUESTIONS / ANNOTATIONS  (synthesis residue from Step 7.1)
-----------------------------------------------------------------------

Notes for the synthesis pass and downstream Steps. NOT template
content.

7.1  comment = "#>" and collapse = TRUE in setup
     Plan §Step 7.1's verbatim setup chunk omits both; style guide §4
     ("Default setup chunk") includes both. This template includes
     both, on the reasoning that the style guide is the operational
     authority for vignette chunk options and that the inclusion is
     additive rather than contradictory. DPprior quick-start.Rmd uses
     the same pair. Confirmed by both drafters in Step 7.1.

7.2  df_print: tibble
     Plan §Step 7.1 specifies df_print: tibble. rmarkdown::html_vignette
     honors df_print: default | kable | tibble | paged. tibble invokes
     tibble::print.tbl_df(). multisitedgp_data has a custom print()
     method (R/class-multisitedgp_data.R), but tibble subclassing means
     df_print: tibble produces consistent narrow-display behavior.
     No action - flagged for PI awareness if any vignette's primary
     output looks unexpectedly truncated.

7.3  apa.csl produced separately
     The apa.csl file at vignettes/apa.csl is fetched verbatim from the
     official Citation Style Language repository
     (https://github.com/citation-style-language/styles, file: apa.csl,
     "APA Style 7th edition" by Brenton M. Wiernik et al., CC-BY-SA 3.0).
     It is not produced by drafting agents. To refresh:
       curl -sSL https://raw.githubusercontent.com/citation-style-language/styles/master/apa.csl \
            -o vignettes/apa.csl

7.4  Title bullet middle-dot in VignetteIndexEntry
     The IndexEntry strips the bullet (·) and em-dash (—). The visible
     title in the vignette body keeps both. CRAN's vignette-index
     scanner tokenizes on these characters; bare ASCII for the
     IndexEntry avoids the regex hit.

7.5  Author byline
     Plan §Step 7.1 and style guide §7 both specify bare "JoonHo Lee".
     No role suffix, no grant ID, no ORCID in the byline. ORCID lives
     in DESCRIPTION Authors@R, not the vignette frontmatter.

7.6  M-track length budgets are estimates
     The M-track ranges in §6.4 are conservative estimates derived from
     the per-vignette plan content. If a Step 8.x agent finds the
     content naturally exceeds these, reasonable overshoot is allowed
     - flag in the Step log for PI confirmation.

7.7  pkgdown::build_site() is intentionally deferred
     Until both Phase 7 and Phase 8 vignettes exist, the site build
     will fail because _pkgdown.yml lists all 16 aN/mN slugs in
     articles: contents:. Render individual vignettes only via
     rmarkdown::render() during Phase 7-8.

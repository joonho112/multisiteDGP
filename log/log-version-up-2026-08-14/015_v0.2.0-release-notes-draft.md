## 본문 초안 (영문, GitHub Release 용)

> ### multisiteDGP 0.2.0
>
> A reliability release. The reproducibility contract, the advertised surface,
> and a number of error paths are now explicit and tested. Canonical numerical
> equality and exact binary artifact equality are treated as separate claims.
>
> **Read the breaking changes before upgrading a script that records hashes or
> passes `upstream` to `gen_effects()`.**
>
> ---
>
> #### Breaking changes
>
> **Every `canonical_hash()` value moves.** Schema v4 drops the derived
> diagnostics from the payload, rounds the doubles it does cover to nine
> significant digits, and preserves factor labels and level ordering. Every hash
> recorded under an earlier schema must be recomputed. A schema change can move
> the hash even when the raw data does not.
>
> What you get for it: **the canonical numerical hash is portable.** Seeded
> wrappers pin `Mersenne-Twister` / `Inversion` / `Rejection`, so the same design
> and seed no longer depend on the caller's active RNG kind. Verified on
> `linux-release`, `linux-devel`, `linux-oldrel`, `macos-release` and
> `windows-release`.
>
> **`gen_effects()` no longer takes `upstream`.** Layer 1 starts the pipeline, so
> it has no upstream. The argument aborted whenever it was non-`NULL`, so it never
> did anything. Remove it. The identically named first positional argument of the
> Layer 2, 3 and 4 functions is unaffected.
>
> **`scenario_audit()` gains columns.** Code that selects audit columns by
> position or checks the column count needs updating. Select by name. `pass` is
> now literal: `TRUE` only for `status == "PASS"`.
>
> ---
>
> #### The catalog is six built-ins plus `User`
>
> The package generates seven shapes, not eight. `true_dist = "DPM"` is a
> reserved slot: the argument accepts the string, but built-in Dirichlet-process
> sampling is deferred, so reach it through a `g_fn` bridge. This was already
> true in 0.1.x. Only the advertising was wrong.
>
> ---
>
> #### Fixes you will notice
>
> - **`scenario_audit()` works on every shape.** Auditing a design that declared
>   `SkewN`, `ALD`, `Mixture` or `PointMassSlab` used to abort the whole run.
>   Four of seven shapes could not be audited at all. Groups A, B and D are now
>   judged normally and only the Group C distributional gates are skipped, since
>   they need a package-defined reference distribution. An unmeasured diagnostic
>   is not a violated one, so the gates are skipped rather than failed.
> - **Engine A2 verifies mean and SD separately and fails closed.** A shared
>   residual floor let an ill-conditioned SD calculation authorize an arbitrarily
>   large mean miss: the old solver accepted a target mean of 100 with a fitted
>   mean near 5.12 at `cv = 1e-5`. That case now solves to mean 100, SD 0.001.
> - **A named `beta` may omit the intercept**, matching what an unnamed `beta`
>   already allowed.
> - **Diagnostics use their target scales.** Gaussian-copula `pearson_corr` is
>   checked against the achieved latent Pearson correlation, and the Group C KS
>   statistic uses a calibrated one-sample test against the analytic CDF.
> - **`error_catalog()`** exposes the stable E01--E30 condition, affected API and
>   remedy table, generated from the traceability ledger so help and tests share
>   one source.
> - **The Student-t warning no longer recommends a value it warns about.** Excess
>   kurtosis diverges at `nu = 4` as well as below it. Numerical behaviour is
>   unchanged; only the warning boundary and wording moved.
> - **Caterpillar plots are readable at realistic `J`.** Labels are thinned to at
>   most 25 in effect order. Every data row still draws.
> - **`scenario_audit(parallel = TRUE)` says when its workers see another
>   package.** A `future::multisession` worker resolves multisiteDGP from the
>   installed library, which is wrong under `pkgload::load_all()`: the workers
>   would audit a different version than the one you are developing. Installed
>   packages and sequential plans stay silent.
>
> ---
>
> #### Preset and migration claims now match their sources
>
> `preset_jebs_strict()` uses the appendix's literal lower site-size bound,
> `nj_min = 5`. `preset_walters_2024()` is labelled a Walters-anchored proxy, with
> its metadata separating direct source anchors from derived values and package
> assumptions. The siteBayes2 migration guide gives executable scale conversions.
>
> ---
>
> #### Verification
>
> - `R CMD check --as-cran`: 0 errors, 0 warnings, 0 notes
> - CI green on five platforms, plus extended tests, coverage and lint
> - 13 validation experiments pass against a recorded source digest
> - Test suite: 5350 assertions, 0 failures, 0 skips
>

## 넣지 않은 것과 그 이유

- **결함 번호(D-038 ~ D-064)** — 내부 추적 번호입니다. 외부 독자가 조회할 곳이 없습니다.
- **Phase/Step 번호** — 같은 이유입니다.
- **"모든 결함을 찾았다" 류의 문장** — 근거가 없습니다. 이번 사이클에서 CI 가
  로컬 초록색 아래 숨어 있던 결함을 세 건 더 찾았고, 그것이 마지막이라는 증거는 없습니다.
- **CRAN 제출 언급** — 아직 결정된 바가 없습니다.

## 정확성에 대한 메모

"Verified" 절의 숫자는 전부 실측값입니다. 다만 두 가지를 정확히 적어 둡니다.

- **`0 notes` 는 로컬과 CI 5 cell 기준입니다.** 설치 크기가 CRAN 임계에 가까우므로
  CRAN 제출 시에는 NOTE 가 붙을 수 있습니다.
- **"5350 assertions, 0 skips" 는 `NOT_CRAN=true` 로 소스 트리에서 돌렸을 때입니다.**
  `R CMD check` 는 tarball 에 포함되지 않는 개발 전용 파일을 읽는 테스트 54 건을
  필연적으로 건너뜁니다. 두 숫자는 서로 다른 것을 재며, 둘 다 참입니다.

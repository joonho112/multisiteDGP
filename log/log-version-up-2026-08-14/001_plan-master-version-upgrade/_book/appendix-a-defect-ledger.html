18  부록 A — 결함 원장 스키마

Phase 2 가 만드는 defect-ledger.csv 의 스키마와 운영 규칙이다. Phase 4 · 5 · 7 · 10 이 이 원장을 소비한다.

18.1 파일 위치

log/log-version-up-2026-08-14/defect-ledger.csv

CSV 로 두는 이유: R 에서 바로 읽어 집계할 수 있고, git diff 에서 변경이 보이며, tools/traceability/ 의 기존 ledger 관행과 일치한다.

18.2 열 정의

열 타입 필수 설명
id 문자 ✓ D-NNN 형식, 3 자리. 부여 후 변경하지 않는다
title 문자 ✓ 한 줄 요약. 증상이 아니라 결함을 서술
area 열거 ✓ infra / repro / test / surface / kernel / api / deps / perf / docs
severity 열거 ✓ P0 / P1 / P2
discovered_in 문자 ✓ step2.3 같은 Step 번호, 또는 external-review-r1
symptom 문자 ✓ 관찰된 현상. 사용자가 무엇을 겪는가
root_cause 문자 원인. 감사 시점에 모르면 비워두고 수정 Phase 에서 채운다
repro 문자 ✓ 재현 절차. 실행 가능한 명령 또는 단계. P0 는 필수
evidence 문자 ✓ 증거 파일 경로 (evidence/phase02/...)
threatens 문자 위협하는 성공 기준 (G2, G4 등). P0 는 필수
owner_phase 문자 ✓ 처리 담당 Phase (phase04 / phase05 / phase07 / phase10)
fix_approach 문자 수정 방향. Phase 3 결정에 종속되면 그 결정 ID (D1, D2)
status 열거 ✓ 아래 참조
regression_test 문자 회귀 테스트 위치 (tests/testthat/test-xxx.R:42)
commit 문자 수정 커밋 SHA
resolution_note 문자 종결 시 한 줄. wont-fix 는 근거 필수
related 문자 관련 결함 ID, 쉼표 구분

18.3 status 값

값 의미
open 등재됨, 미착수
in-progress 수정 중
fixed 수정 완료 + 회귀 테스트 통과
wont-fix 수정하지 않기로 결정. 근거 필수
deferred-v0.3 v0.3 으로 이월. GitHub Issue 링크를 resolution_note 에
not-reproducible 재현 실패. 강등 또는 삭제 후보
duplicate 다른 행과 중복. related 에 원본 ID

18.4 우선순위 기준

P0 — 릴리스 차단. 다음 중 하나에 해당한다.

  • 성공 기준 G1–G7 중 하나를 직접 위협한다
  • 사용자에게 잘못된 수치를 준다 (조용한 오류)
  • 문서가 사실이 아닌 것을 주장한다
  • CI 를 red 로 만든다

P1 — 고쳐야 하지만 차단하지 않는다.

  • 사용자에게 보이는 결함이되 우회 가능하다
  • 오류 메시지가 불친절하다
  • 커버리지 공백
  • 성능 회귀 (심각하지 않은 수준)

P2 — 개선.

  • 내부 정합성
  • 코드 품질
  • 향후 유지보수 편의

18.5 운영 규칙

  1. Phase 2 가 채우고 Step 2.9 에서 닫는다. 이후 Phase 는 소비한다.
  2. Phase 2 이후 발견분의 기본 severity 는 P2 + deferred-v0.3. P0/P1 로 올리려면 위 기준에 해당함을 근거와 함께 보여야 한다. 예외는 외부 리뷰 Critical — 자동으로 P0.
  3. P0 는 재현 절차가 실제로 실행되어 확인된 것만. 재현 안 되면 not-reproducible 로 강등.
  4. 근본 원인이 같으면 한 행. 증상이 10 개여도 원인이 하나면 한 행이고 symptom 에 10 개를 나열한다. 이것이 Linux snapshot 실패 10 건을 다루는 방식이다.
  5. wont-fix 는 근거가 필수. “시간이 없어서” 는 근거가 아니다 — 그건 deferred-v0.3 이다.
  6. 모든 수정 커밋은 id 를 인용한다.
  7. Phase 7 종료 시 P0 전건이 fixed 또는 wont-fix. 하나라도 open 이면 Phase 7 이 끝나지 않은 것이다.

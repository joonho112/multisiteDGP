── 1. 해시가 double 을 반올림하는가 ──
  1 값에 2 ULP 섭동 → canonical 표현 동일?  FALSE 
  digest 동일?  FALSE 
  → 반올림 없음. 최하위 비트가 곧 해시.

── 2. 기본 경로가 nleqslv 를 타는가 ──
  기본 engine: A2_modern 
[1] "nleqslv"
  sim_multisite() 1 회 호출 중 nleqslv 호출 횟수: 5 
  → 기본 경로가 반복 solver 를 탄다. 

── 3. solver 해의 결정도(determinacy) ──
  수렴한 시작점: 5 / 5
  alpha  범위: [6.249980880736187, 6.2499808807434469]
  beta   범위: [0.062499836366643323, 0.06249983636672559]
  시작점에 따른 해 차이: alpha 5.23e+03 ULP, beta 5.93e+03 ULP
  잔차 노름 범위: [1.11e-15, 6.38e-13]  (ftol = 1e-12)
  → 해는 ftol 수준까지만 결정된다. 비트 수준으로 결정되지 않는다.

── 4. tolerance 섭동 = 플랫폼 차이의 대리 실험 ──
  ftol=1e-12   alpha=6.2499808807366311  base 대비        0 ULP
  ftol=1e-13   alpha=6.2499808807417967  base 대비 3.72e+03 ULP
  ftol=1e-11   alpha=6.2499808807366311  base 대비        0 ULP
  ftol=1e-10   alpha=6.2499808807366311  base 대비        0 ULP
  → tolerance 를 1 자릿수만 바꿔도 해의 최하위 비트가 달라진다.
    플랫폼별 libm/컴파일러 차이도 동일한 효과를 낸다.
